# isaccoso.github.io

Il sito personale di Gianluca Iunco si è trasferito su **https://www.gianlucaiunco.com/**.

Questo repository resta online solo per reindirizzare i vecchi indirizzi.
GitHub Pages non supporta redirect 301, quindi:

- `index.html`, `en/index.html` e `404.html` reindirizzano alla pagina corrispondente
  del nuovo sito (`meta refresh` + `rel="canonical"` + `location.replace`);
- `about.md`, `llms.txt` e le versioni in `en/` sono testi brevi con il nuovo indirizzo.
